# 预售名额管理演示

纯标准库实现（SQLite + http.server，无第三方依赖）。覆盖预售活动、订单时间线、
尾款页、异常款队列、名额回补与库存看板；支付使用模拟适配器（支持延迟回执与
重复回执）；内置虚拟时钟，启动即预置全部临界时刻样例。

## 启动

```bash
python3 app.py            # 首次自动建库并预置样例
python3 app.py --reseed   # 清空并重新预置
# 打开 http://127.0.0.1:8000
```

虚拟时钟：真实 1 秒 = 虚拟 10 秒，也可在「库存看板」手动 +10 分钟 / +1 小时 / +1 天。
后台每 2 秒自动投递到期回执、扫描逾期订单。

## 预置样例（启动即可见）

| 活动 | 临界场景 |
|---|---|
| 极光降噪耳机（5 名额） | 尾款窗 3 分钟后开始；1 笔尾款回执延迟 5 分钟（窗内自动结清）、1 笔延迟 12 分钟（晚于截止，释放后迟到付款）；1 笔部分支付；规则 v1→v2（调价+改规格），老单锁 v1、新单锁 v2 |
| 彗星轻智能手表 | 尾款期明天才开始，尾款台只显示「未开始」，不显示可付金额 |
| 脉冲运动手环 | 已取消预售：未付订单退定金终止，已付清订单继续履约；含结清后重复到账（异常款）与同号回执重放（忽略） |
| 星云桌面音箱 | 尾款窗已截止并释放；含「窗内付款、回执截止后才送到」竞争样例与部分支付逾期，各挂异常款 |

## 页面

- **活动页**：定金/尾款窗口状态、规则版本历史与新版本发布、取消预售、下单。
- **订单页**：定金、尾款、已付合计三栏分列；时间轴标注定金/尾款付款窗口与全部
  资金/释放/异常事件；支付回执台账标明是否实际入账。可模拟尾款支付（任意金额、
  回执延迟分钟数）、在途回执立即补投、同号回执重放、配货发货、客服处理请求。
- **尾款台**：只列待付尾款订单；窗口开始后才显示**应付金额**与**截止时间**，
  部分支付订单显示已付与剩余。
- **异常款队列**：释放后迟到付款、结清后重复/超额到账、超应付金额、部分支付
  逾期、取消后到账。财务可**退款 / 批准占用回补名额发货 / 驳回**；其他角色只读。
- **处理请求**：客服只能查看订单并发起请求（提前释放、取消活动、人工核查），
  运营/财务审核。
- **库存看板**：每个活动显示**预留 / 已付 / 释放 / 可售**与超卖校验。

## 关键规则

- **下单占名额并锁定规则版本**：订单快照保存定金、尾款、规格；之后发布新版本
  或改规格不影响老订单（规格可经客户确认后更新，价格仍按锁定版本）。
- **尾款部分支付**：可多次入账，累计等于应付才转「待配货」（预留→已付）。
- **回执幂等**：`receipt_no` 唯一，重复回执只记录忽略事件，绝不二次入账。
- **逾期释放与支付竞争**：所有写操作走 `BEGIN IMMEDIATE`，SQLite 全库串行化，
  「投递回执」与「逾期扫描」不可能同时提交——一个订单要么付款成功进入配货，
  要么释放名额并退款，不会既退款又发货。
- **释放后迟到付款**：不入账、不动名额，挂异常款；财务可选择退款，或在仍有
  可售名额时批准占用回补名额恢复履约（名额计数守恒，库存表带
  `reserved+paid+released<=stock` CHECK）。
- **取消预售**：未付/部分支付订单取消并原路退定金及部分尾款；已付清订单继续
  配货；取消后到账落异常款。
- **角色**：运营（规则版本、取消、发货、规格确认）、财务（异常款审核、请求
  审核）、客服（只读 + 发起请求）。
- 金额单位为分，页面黑色加粗等宽数字；白底 + 商品色点缀，无渐变。
